# Roadmap

A rough phasing plan. Open an issue to discuss changes.

## Phase 0 — Foundations
- [ ] Choose tech stack and architecture (multi-tenant vs single-tenant, database, API style)
- [ ] Project setup: linting, tests, CI, Docker-based local dev
- [ ] Auth, roles and permissions (Admin, HR, Manager, Employee)

## Phase 1 — Core HR
- [ ] Company, branches (with state), departments, designations
- [ ] Employee master and documents
- [ ] Employee self-service portal

## Phase 2 — Attendance & Leave
- [ ] Leave types and policies, accrual and carry-forward
- [ ] State-wise holiday calendars
- [ ] Attendance, shifts and regularisation

## Phase 3 — Payroll & Compliance
- [ ] Salary structures and components
- [ ] Monthly payroll run, LOP, arrears, payslips
- [ ] PF, ESI, Professional Tax, LWF
- [ ] TDS (old and new regimes), investment declarations, Form 16
- [ ] ECR, challans and bank transfer files

## Phase 4 — Beyond
- [ ] Onboarding/offboarding, F&F settlement, gratuity
- [ ] Expenses and reimbursements
- [ ] Reports and analytics
- [ ] Indian language support, mobile app, integrations
