# Instructions for AI agents

1. **Read `HANDOFF.md` at the repo root before doing anything.** It holds the current state, decisions, next steps and open questions.
   - `HANDOFF.md` is **local only**: it is gitignored and never committed or pushed. Never remove it from `.gitignore` or force-add it.
   - If it doesn't exist (for example, on a fresh clone), create it with these sections: Project, Current state, Decisions so far, Next steps, Open questions, How to run / test, Gotchas, Change log.
2. **Whenever you write or change code, update `HANDOFF.md` before you finish.** Cover what you did, decisions and why, what's next, how to run/test and any gotchas. Rewrite stale parts rather than only appending, and add a dated change-log entry.
3. Follow [CONTRIBUTING.md](CONTRIBUTING.md): no hard-coded statutory rates, no real personal data, and tests for all payroll/tax logic.
